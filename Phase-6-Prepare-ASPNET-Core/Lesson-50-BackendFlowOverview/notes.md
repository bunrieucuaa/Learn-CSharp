## 1. Tóm tắt kiến thức Bài 50
* **Request-Response Lifecycle:** Vòng đời của một HTTP Request từ Client Angular chọc qua Internet, đi qua Web Server, Middleware Pipeline, Routing, Controller, Service, Repository, Database và trả Response ngược lại.
* **Đồng bộ hóa kiến thức:** Việc kết hợp đầy đủ các mảnh ghép kiến thức từ biến, hướng đối tượng, bất đồng bộ, DI, phân tầng đến giao thức mạng tạo nên cấu trúc hoàn chỉnh của một ứng dụng web hiện đại.

## 2. Checklist đánh giá mức độ sẵn sàng chuyển sang học ASP.NET Core & Angular
Hãy tự đánh giá mức độ hiểu biết của bản thân trước khi chính thức mở Visual Studio code dự án Web thật:
- [ ] Bạn đã tự tin giải thích được cách luồng đi của một HTTP Request từ trình duyệt Angular chọc xuống Database qua ASP.NET Core Web API chưa?
- [ ] Bạn có nắm vững cơ chế hoạt động của Dependency Injection (Transient, Scoped, Singleton) để cấu hình dự án ASP.NET Core không?
- [ ] Bạn có biết cách viết các hàm xử lý bất đồng bộ sử dụng `async` và `await` để tránh bị nghẽn Web Server không?
- [ ] Bạn đã làm chủ được tư duy thiết kế đường dẫn RESTful API chuẩn quốc tế (chỉ dùng danh từ số nhiều, dùng HTTP Method đại diện cho hành động) chưa?
- [ ] Bạn có biết cách cấu hình JSON serializer để tự động map PascalCase của C# sang camelCase của Angular chưa?
- [ ] Bạn có nắm vững nguyên tắc thiết kế "Skinny Controller, Fat Service" để viết code phân tầng sạch đẹp không?
